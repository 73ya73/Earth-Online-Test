# 测测你的精神回血机制

Earth Online · Recharge Personality Test v1.5。沿用 React、TypeScript、Vite 静态项目和 Windows XP Luna / 原创像素设计。题库唯一来源为《分数 (8).xlsx》：13 题、70 个选项、六种回血机制；不需要数据库或付费 API。

## 本地运行与校验

使用 Node.js 22.12 或更新版本，运行 `npm ci`，然后 `npm run dev`。执行 `npm run build` 后再运行 `npm test`（自动化交互测试读取真实构建产物）。`npm run simulate` 运行 10,000 次固定种子的合法答题模拟，仅检查算法结构，不代表人群分布。

Python 需 openpyxl。运行 `python scripts/convert_excel.py "Excel绝对路径"` 导入题库，运行 `python scripts/verify_excel.py "Excel绝对路径"` 独立逐格核对。源文件只读。当前 420 个评分单元格包含 23 个数字和 397 个 null，均与 Excel 一致；报告见 reports/data-validation.json 和 excel-verification.json。

## 题库和多选

各题选项数为 4/7/4/5/5/5/4/5/7/6/6/5/7。Q9、Q10 最多选两项；Q13 的 A–F 可多选，G 与其他选项互斥；其余单选。下一题要求至少选择一项，返回可修改。选项保留原题文案、顺序、behaviorTag、answerNature、scoringEnabled、scores 和 sourceRow；选择约束来自 v1.3/v1.5 说明。Q10 的 A–D 最多两选；E、F 各自独立，与彼此及 A–D 互斥，允许再次点击取消。E/F 使用圆形 Radio 风格，其余多选使用方形 Checkbox。

Q9-D 保留 THINK=2，Q9-F 保留 ACT=2，不按行为标签改分。Q10、Q13 不计分。新表已将 Q10-E/F 标签改为 T13 无明显变化、T14 负向体验；按新表原样保存，移除 v1.2 的临时待校准覆盖标签。其余未评分选项也完整记录标签和答案性质。

## 计分与状态占比

内部沿用 Excel 的 ACT/RESET/SOCIAL/LUCKY/THINK/SAVE；文档 REST/LUCK 是 RESET/LUCKY 的别名，不添加新机制。只累加参与评分选项的明确数字，空白不推断赋分；多选各项累加，同一题对同机制只增加一道正分证据。合法多选组合参与理论最高分计算，目前仍为 5/6/8/8/6/5。

主人格判定沿用试行配置 pilot-1.3：原始分 / 各型理论最高分比较；至少两道不同题目的正分证据才能进入候选。最高完全并列时展示全部最高候选；唯一最高且其他候选差距不超过 0.1 时展示混合倾向，否则明确单一候选。容差 1e-9。不随机、不默认返回 ACT；完成全部 13 题但没有合格候选时显示 EXPLORING 探索状态；未完成时仍为 insufficient，不提前给结果。规则尚待校准，非科学心理测评。

新增 System Status 与主人格算法分离：每项原始分 / 六维原始总分 × 100，保留一位小数，六项合计约 100%。异常输入安全显示 0%；低证据仍可展示已有得分占比，但不强行判定人格。Top 3 按原始分排列，只列正分属性，第三名并列全部保留。不是人格判断值、心理准确率或能力评价。

## 界面与隐私

欢迎页为安装向导；答题使用绿色进度条；单选圆形、多选方形使用统一 ChoiceOption；题型说明位于题干下的细线区域，Q13 分多选区域与独立互斥选项。桌面多选项题采用双列紧凑布局，手机单列自然滚动。结果常规页优先展示名称、原图案、代表文案、六维属性、Top 3 和操作按钮。系统鼓励、回血建议、原有长文放入详细分析折叠区；回答线索与记录、推荐阅读、计分说明仍是真实标签页，支持方向键和 Home/End。保留六套人格图案、文案及每型两本书籍。新增探索状态像素地图电脑、温和鼓励与建议，以及两本书；来源见 reports/reading-sources.md。七种结果使用同一模板和导出布局，探索不增加得分维度。

PNG 导出使用独立 Canvas 状态卡，1080×1350（4:5），包含结果、原图案、文案、六维条、Top 3、非诊断说明和版本号。分享采用原生分享或复制普通网站链接，不包含答案。XP 窗口的最小化、最大化、关闭保留进度、桌面恢复均保留。

所有答案仅保存在当前浏览器。v1.5 使用独立 earth-recharge-v1.5 键和答案数组，拒绝无效、超限或互斥冲突的存档。v1.2/v1.3 数组进度逐项校验后可恢复；旧 Q10 如果包含 E/F 混选会要求重新选择，不擅自代选，旧版本原数据仍保留。重新测试会清除 1.2/1.3/1.5 进度，但不删除历史存档。无账号、无回答上传，使用系统字体和原创背景，不依赖外部版权图片。

## v1.5 我的存档

Git 历史确认旧入口只恢复当前答题进度，没有多次历史库。现在保留进度恢复，并在结果页提供“保存到我的存档”，与 PNG 导出分开。历史库使用固定 `earth-recharge-saves-v1` 键、schemaVersion=1，不随版本号换键。记录含唯一 ID、测试会话 ID、时间、版本、类型、原始分数、百分比、答案，以及完整题库、人格文案、书籍、图案绘制指令、计分结果和配置快照。

同一测试会话只存一次，刷新也不会重复；重新开始产生新会话，允许同日相同或不同结果分别存档。存档成功弹出 Save Complete；“+1 MEMORY”为仪式文案，不加 SAVE 分数。写入失败不会显示成功，也不清空旧数据。

My Saves 是独立 XP 文件夹窗口，含地址栏、像素文件网格、状态栏和实际可用的最小化/最大化/关闭。鼠标单击选择，双击打开；Enter 与触屏可直接打开。删除需二次确认，取消不改数据。打开历史结果使用保存时的快照，不调用当前分类器覆盖旧结果。历史 PNG 也使用当时百分比、图案、时间与版本。

旧格式数组及残缺记录保留可读字段，缺少的题文与结果不推断，未知字段不丢弃；无法读取的存储不自动清空或覆盖。历史库与进度分开，重测和进度恢复均不清空历史。数据仅在当前浏览器、设备和网站地址内可用；本地预览与 GitHub Pages 不共享存档，清除网站数据可能导致丢失。没有云同步或回答上传。

本轮修改文件、Git 历史检查与验收见 `reports/v1.5-update.md`。v1.3 报告为历史记录。
