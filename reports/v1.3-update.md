# v1.3 修改与验收

在原有 React + TypeScript + Vite 项目上继续修改，保留 Windows XP / Y2K 风格、六型名称、核心文案和原图案。仅新增探索图案分支，六型绘制指令未修改。此版本尚未推送或覆盖 GitHub Pages，等待用户确认发布。

## 新表与 v1.2 的差异

《分数 (8).xlsx》仍为 13 题、70 个选项；与上一表只有四处内容变化：A57 的 Q9 题干去掉多选括号说明，A66 的 Q10 同样去掉；C71 改为 T13 无明显变化，C72 改为 T14 负向体验。420 个评分单元格没有任何变化：23 个明确数字、397 个 null。Q9-D THINK=2、Q9-F ACT=2 原样保留。移除旧临时反馈覆盖字段，按新标签展示。

## 交互与模板

- 统一 ChoiceOption：单选圆形 Radio、多选方形 Checkbox，统一尺寸、描边、蓝色选中背景；复选绿色勾，单选蓝色圆点；移除右侧重复的选择符号。使用原生输入保留键盘行为。
- 所有题型辅助说明与题干分离。Q9/Q10 最多两项，可只选一项；数量读取题目配置。Q13 的 A–F 和 G 分组说明，最多六项、G 互斥、可取消到空、无答案无法继续、返回和刷新恢复。
- 多选得分按当前答案重算；重复点击、取消、返回修改不积累旧分。同题证据仍去重，空白不补分。
- 桌面根据 viewport 压缩上方留白，六项及以上的题目使用双列（保持 DOM 原序，按行 A/B、C/D 阅读）；手机保持单列、至少 48px 选项区域和正常页面滚动。切题恢复顶部；不使用整体缩放或内部固定滚动区。
- 七种结果共用同一布局、边框、内边距与分享卡。左右顶部对齐，介绍与图案自然撑开，窄窗口上下排列，详细分析继续折叠。
- 仅兼容迁移已验证的 v1.2 数组存档；重置清除两版键。更早题号含义不同的版本不迁移。

## 探索状态触发条件

不更改分数、理论上限或原候选阈值。完整、合法提交全部 13 题后，若所有机制都未达到“原始分 > 0 且至少两道不同题目的正分证据”，候选列表为空，才显示 status=exploring。EXPLORING 不加入 KEYS、totals、百分比或计分表。

未完成答案且候选为空为 insufficient，不提前判定探索。reason 区分 all-zero 与 low-evidence；完整真题全零不可达，因为必答 Q4 每项都有 2 分，但保留防御处理与测试。

正常并列：达到证据门槛的最高比较值完全相同时，保留所有最高候选，status=tie；不会因为任意两项原始分相同改为探索。近似候选：唯一最高且其他合格候选差距不超过 0.1，继续 status=mixed。此处是候选区分度不足，明确展示组合，不额外发明“探索分差阈值”。单一明显领先仍为 single。所有结果确定可复现。

## 验证

- Excel 独立核对通过：13 题、70 选项、420 分数字段，题文、顺序、性质、标签、参与评分标志均与新表一致。
- npm run build 使用 /Earth-Online-Test/ 成功；npm test 共 41 项全部通过，包含所有七种结果的完整页面和 1080×1350 PNG 导出、六维数值、Q13 取消/返回恢复、只选一项计分、正常并列与探索隔离、旧存档迁移等。
- 固定种子模拟 10,000 次：六型唯一胜出数量与 v1.2 完全相同（898/1207/1057/1888/971/772）；正常并列 639、近似组合 749；旧版完整作答的低证据 1819 改为探索状态 1819。此模拟不是人群分布或测评校准。
- 浏览器重点检查 Q9/Q10/Q13：1366×768、1440×900、1920×1080 下导航均在视口内；375/390/430px 手机无横向溢出，必要滚动可访问导航。18 组布局测量见 v1.3-responsive.json，内滚动区数均为 0；桌面选项至少 44px、手机至少 48px。切题 scrollY=0。
- 已真实下载探索卡，尺寸 1080×1350，图案、长描述、六维条和版本未裁切；另外六型通过同一导出路径回归测试。系统鼓励、建议、书籍标签和计分表均完整。

## 待进一步确认的规则

本版沿用 minEvidence=2、各型理论上限归一化、nearTieGap=0.1、epsilon=1e-9，未根据模拟比例调整任何权重或阈值。请后续确认这些试行阈值是否作为正式规则；如希望将某类多候选也纳入探索，需要另行定义条件。Excel 空白仍表示未定义，程序只累加明确数字，不擅自确认为已填零。
