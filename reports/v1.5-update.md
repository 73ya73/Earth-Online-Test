# v1.5 修改与验收

依据《地球Online - 精神回血系统检测 v1.5.txt》，在本地 v1.3 项目上增量修改。未推送 GitHub，未覆盖线上 v1.2。当前源代码、测试、源码包为 v1.5。

## 历史检查结论

检查本仓库全部提交：ed7a149、726b531、660bc54、5c89d99、b0160e7。最早 storage.ts 的 earth-recharge-pilot-1 仅保存 answers/index/page；v1.1 与 v1.2 同样只保存当前进度。旧“我的存档”调用 onResume，未发现保存多次结果、自动历史存档、单条删除或历史数据库。因此保留进度恢复，并按本次文档允许的手动方式补齐独立历史库，没有声称恢复不存在的旧历史数据。

## 本轮行为

- 答题、处理中、结果使用同一桌面外壳和定位；不设额外大固定高度。稳定预留滚动条空间，保留最大化行为。
- 结果页“保存到我的存档”与“保存结果图片”独立；成功显示 XP Save Complete，包含“查看我的存档”“继续探索”和约 0.65 秒完成动画；失败不显示成功。+1 MEMORY 不参与计分。
- My Saves 为独立 XP 窗口：地址栏、桌面 3–5 列/手机 2 列图标网格、状态栏、空文件夹提示、最小化/最大化/关闭、任务栏恢复。存档文件名包含类型、日期、时间和 ID 后缀。同日多次测试独立保存，同一会话重复保存会拦截。
- 桌面快捷方式和存档文件：鼠标单击只选中、双击打开；标准 onDoubleClick，没有计时器模拟。原生按钮 Enter 激活；pointerType=touch/pen 时轻点可打开。空白区域无打开事件，不会创建重复窗口。
- 历史页显示 Historical Save、原时间与版本；只读展示当时的结果、分数、百分比、文案、书籍、题目和答题记录，不重新调用当前题库分类。可返回存档、导出当时的 PNG 或重测。
- Q10 A–D 最少一项、最多两项；E、F 各自只能独立存在，点击可取消，选 A–D 会清除 E/F，反之同样清除。E/F 为可取消的圆形 Radio，支持方向键切换。分数不因控件类型而禁用。

## 存储与兼容

长期历史键 earth-recharge-saves-v1，schemaVersion=1。每条记录包含 id、sessionId、createdAt、version、resultType、totals、percentages、answers，以及 snapshot：完整结果/理论上限/证据/配置、当次题库、人格资料与书籍、展示信息、属性和像素绘制指令。无后端、无账号、无额外个人信息、无上传或同步。

进度键 earth-recharge-v1.5；从 v1.3/v1.2 逐项校验恢复。旧 Q10 混合 E/F 的非法组合不会自动代选，要求重新回答 Q10，其他有效进度保留，旧键原数据也保留。重测只清理进度键，绝不清空历史键。

历史库兼容数组及本版 envelope；残缺或无法验证的单条记录降为部分信息视图，不根据当前数据补写旧结果，也不影响其他完整记录。未知字段和原始内容保留；删除只移除确认的那一条。无法解析/未知库格式阻止覆盖，存储额度不足或写入失败不显示成功、不丢旧字节。浏览器历史库不能补回已被用户清理的网站数据。

本地存档按浏览器、设备及网站 origin 隔离；本地预览与 GitHub Pages 记录不自动互通。浏览器验收使用独立的本地端口，所有示范记录均由实际走完测试后创建，项目没有预填假数据。

## 数据和功能保持

与交付的 v1.3 源码包逐文件比较：scoring/engine.js、answers.js、status.js、六型文案、六型及探索像素图、探索文案和 profiles.ts 均完全一致。13 道题全部题干、70 个选项、行为标签、答案性质、参与评分标志及所有分数不变，只有 Q10 新增 exclusiveOptions=[E,F] 与 exclusiveControl=radio。证据见 v1.5-preservation.json。

独立核对 Excel：420 个分数单元格全部一致，23 个明确数字、397 个 null。仍沿用 pilot-1.3 的主人格判定配置（两题证据、原上限归一化、0.1 近似差距）；应用版本是 1.5，不意味着重新校准规则。六种人格、探索状态、正常并列、推荐阅读、属性面板及 PNG 导出保留。

- 真实浏览器完整走通：完成测试 → 保存 → Save Complete → My Saves → 双击文件 → Historical Save → 返回文件夹；另外完成三次同日独立测试，取消删除保留 3 条，确认删除仅移除选定的验收记录，余下 2 条正确保留；刷新和重测均不丢失。
