## 本地实现

- 集中本地化：src/i18n/en-questions.json 原样保存正式题干/选项；en-ui.json 管理通用界面、人格说明、书单理由及错误提示，dev-ui.json 只随开发面板加载。题库英文未自行改写；工作簿未提供的界面/人格英文由现有中文翻译。所有 questionId、optionId、behaviorTag、answerNature、scores 共用原数据，中文题库文件未改动，Q11 保留已确认的最新题干。
- 首页、答题、结果、历史记录容器、帮助、存档窗口、图片下载和错误提示可切换中英文。统一“中文 / EN”入口在应用菜单栏；locale 独立保存，切换不清答案、不新建 submission_id、不触发新一份研究记录。英文分享卡按单词换行并限制文本区域，原像素画及 XP 风格保留。
- 历史存档继续使用原快照，不重新跑新算法；来源语言没有正式译文的旧快照内容保持原样，避免用当前译文覆盖过时题目/文案。新存档记录 UI 版本、算法版本及保存时语言；当前测试的算法也写入进度，重新打开或改变预览配置不重新解释已完成结果。
- 六种原始分数和原算法完全保留。新规则在 scoring/v17-config.js 独立配置，在 v17.js 复用原始计分，仅替换最终判定。接口代码继续使用 RESET/LUCKY，REST/LUCK 只作别名，避免破坏既有分数字段。
- 新规则：最高原始分<3，或最高层没有两题证据支持，返回 EXPLORING。否则原始领先带（距最高<=1）中至少两个具有两题证据的机制返回 MULTI，保留全部合格候选；否则返回有证据的基础类型。相同原始分按集合处理，不按类型排列顺序硬选赢家。MULTI 有组合专属解释，EXPLORING 明确是证据/得分不足；二者均不是新得分维度。
- 默认及生产新测试继续使用旧算法。只有 DEV 且 VITE_PREVIEW_V17=true 才为新测试选择候选算法；已完成快照按自己的原算法恢复。用户需再次确认后才能正式切换新算法。
- 答题进度沿用原 earth-recharge-v1.5 键与题库协议，避免清空已保存进度；UI/存档版本为1.7，算法版本独立。
- 原可靠队列仍为 30 分钟冷却、最多三轮、每轮三次。按 payload.algorithm_version 选接收入口：旧五字段记录走原 submit-research；新版八字段记录仅走独立配置的新版入口。未配置时新记录保留 pending，尝试次数为零，不发往旧接口；不会伪报已保存，也不无限轮询。语言在完成时固定到 payload，后续切换只改变显示。

## 10,000 次规则模拟

固定种子 20261019，在每题合法选项集合中均匀抽样，非真实人群分布。运行 node scripts/simulate-v17.mjs 可复现。

| 结果 | 数量 | 占比 |
|---|---:|---:|
| ACT | 631 | 6.31% |
| RESET（REST） | 970 | 9.70% |
| SOCIAL | 1069 | 10.69% |
| LUCKY（LUCK） | 1900 | 19.00% |
| THINK | 635 | 6.35% |
| SAVE | 345 | 3.45% |
| EXPLORING | 2007 | 20.07% |
| MULTI | 2443 | 24.43% |

原始最高分并列 31.89%，三种及以上进入 MULTI 2.88%，无机制有两题证据 19.29%，最高分<3 为20.07%。完全并列不会自动成为 MULTI：低分/低证据仍探索。旧算法的多候选比例13.89%，新规则MULTI24.43%，定义变化不能与旧统计直接合并。

不同维度理论最高分：ACT 5、RESET 6、SOCIAL 8、LUCKY 8、THINK 6、SAVE 5，计分机会也不完全相同；改为原始分比较后，维度机会和选项频率可能影响分布。LUCKY19%与SAVE3.45%的差异值得真实数据校准；不为均衡比例修改原权重。全部零分在当前完整真实题库中不可达（Q4必得分），仍用合成边界题库验证零分处理。

## 数据库兼容方案（仅准备）

- 保留 result_type JSONB 数组，不改列类型；旧 `["ACT","SOCIAL"]` 等历史值不改写，不补填算法或语言。
- 新增可空 candidate_types JSONB、algorithm_version TEXT、locale TEXT。旧数据保持 NULL。新记录 result_type 必须是单元素最终结果，例如 `["MULTI"]`，候选另存 `["RESET","LUCKY"]`，scores 仍为原六个键。
- algorithm_version 固定候选版本 pilot-1.7-raw-v1；locale 为完成测试时的 zh/en。EXPLORING 对应空 candidate_types；MULTI 至少两个；基础人格候选数组等于最终结果数组。缺版本的历史记录标作 legacy-unversioned，不猜测其具体旧算法版本。
- 新版 submit-research-v17 对13题、选项、分数、最终结果、候选、版本和语言严格校验并重算，调用单独 SECURITY DEFINER RPC。主键和内容比较保护去重；时间仍用服务端接收时间。旧 RPC/接口继续可用。
- 不开放匿名或 authenticated 表权限，不更改旧记录或 Cron；只允许 service_role 调用新 RPC。前端没有管理员密钥。

详细 SQL/函数准备文件与未来部署顺序见 docs/v1.7-deployment.md。尚未在云端核实新增列，也没有声称新版真实提交已成功。
