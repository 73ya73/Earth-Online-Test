## 本地使用

已有候选服务位于 http://127.0.0.1:5188/ 。菜单栏选择“中文 / EN”，答案、当前进度和同一 submission_id 不因语言切换而变化。开发面板只显示安全状态摘要。

要自行启动，在 PowerShell 项目根目录设置 `$env:VITE_PREVIEW_V17='true'`，然后 `npm run dev`。此开关仅 DEV 生效；`npm run build` 的默认生产新测试仍为旧规则。保持 VITE_RESEARCH_V17_FUNCTION_URL 为空时，新候选记录只存于本地队列，不消耗重试次数，也不发到旧入口。旧队列仍可走旧接口。不要把服务端 key 写入任何 VITE_ 变量。

正式双语仍按旧判定时可单独发布前端，但新记录仍用旧五字段契约，无法保存 locale/algorithm_version。若要同时上线八种新结果与元数据，须先完成下面确认和后台准备，再调整生产算法开关；本轮没有做这一正式切换。

## 本地验证命令

- `npm run build`；设置 EXPECT_RESEARCH_UPLOAD=true 后 `npm test`。
- `node scripts/simulate-v17.mjs`：可复现10,000份候选规则模拟，不改题库。
- `node scripts/sync-research.mjs`；`node scripts/bundle-research.mjs`；`node scripts/bundle-research-v17.mjs`：同步生成材料，无部署。
- `scripts/verify-v17-rpc.mjs`：可选本地 PGlite 内存数据库，不读服务密钥；PGLITE_MODULE 可指向已有运行时模块。
- `scripts/check-v17-browser.mjs`：可选 Playwright/Chrome，检查本地生产预览5187与候选DEV5188；PLAYWRIGHT_MODULE 可指向已有运行时模块。拦截全部外部请求，只写本地测试截图和分享图片。
